---
name: probe-debug
description: 과제 코드의 오류나 테스트 실패를 재현하고 원인을 좁혀 수정한다. 플랫폼이나 감독 설정을 변경하거나 우회하는 용도로 사용하지 않는다.
---

`.probe-kit/AGENTS.override.md`를 따른다. 재현 가능한 실패 신호부터 확보한다.
다중 세션이면 docs/handoff/CURRENT.md의 담당 파일을 확인한다. 공통 원장 수정은 통합 담당자에게 제안하고 자신의 인계와 보고서에 결과를 남긴다.

1. 오류의 마지막 줄만 보지 말고 관련 스택과 직전 변경을 필요한 범위만 읽는다.
2. 작은 입력, CLI 명령 또는 로컬 HTTP 요청으로 실패를 재현한다. 실제 UI 조작은 응시자가 한다.
3. 한 번에 하나의 원인 가설을 정하고 최소 변경으로 확인한다. 원인 없이 여러 변경을 섞지 않는다.
4. 같은 재현 명령으로 수정 후 결과를 확인하고 관련 회귀만 검증한다.
5. 실패 원인, 선택한 수정, 대안과 남은 한계를 DECISIONS와 EVIDENCE에 연결한다.

한 장애에 약 10분을 썼다면 근거가 늘었는지 보고하고 범위 축소나 담당자 확인을 제안한다. 플랫폼 연결이나 권한 문제는 임의 설정 변경 대신 공식 문제 신고를 사용한다.
