# 현재 코드 설명 연습

사전 연습 또는 제출 확정 전인지 문맥으로 확인한다. 실제 후속 서술형에는 적용하지 않는다.
통합 절차, 6개 설명 축, 질문 예시와 피드백 기준은 .probe-kit/prompts/mock_exam_5.md를 읽는다. 키트 저장소 자체에서는 prompts/mock_exam_5.md다.

현재 코드와 실제 결정/실행 근거로 질문한다. 기본은 5문항, 한 문항씩 요청하면 한 번에 하나만 제시한다. 문항 수를 실제 출제 수로 해석하지 않는다.
먼저 문제와 읽은 코드 위치만 보여주고 사용자의 답변 뒤 피드백한다. 가상 예시의 파일/도구/성공을 현재 사실로 옮기거나 이유를 만들어 답하지 않는다.
선택 이유, 약점, 파급과 다음 검증을 실제 근거로 확인한다. 완성 답변 대신 고칠 사실과 코드 위치를 알려 사용자가 다시 설명하게 한다.
출제 중 제품 코드나 공통 원장을 수정하지 않고 배정된 보고 경로만 쓴다. 남은 시간에서 최종 제출 점검 여유를 확보한다.
