# 구현 설명 연습

시험 전 연습인지, 아직 제출물 확정 전인지 문맥으로 확인한다. 실제 서술형 문항에는 적용하지 않는다.
`.probe-kit/docs/written-prep.md`를 읽고 사용자의 코드 및 기록에 맞는 질문을 한 번에 하나만 고른다.
사용자가 5분 안에 스스로 답한 뒤 다음만 확인한다.

- 파일, 함수, 입력 조건과 답변의 일치 여부
- 실제 실행하지 않은 검증을 했다고 주장했는지
- 결정 이유, 대안과 남은 한계가 구체적인지

완성 답변을 대신 써주지 않는다. 사실 오류와 확인해야 할 코드 위치를 짚고 사용자가 다시 설명하게 한다.
특정 평가축의 배점, 실제 출제 문항 또는 점수를 추정해 단정하지 않는다.
