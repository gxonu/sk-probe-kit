---
name: probe-verify
description: 과제 기능 완료나 제출 준비를 판단할 때 요구사항과 실제 실행 증거를 대조하고 실패와 미검증을 구분한다.
---

`.probe-kit/AGENTS.md`를 따른다. REQUIREMENTS의 필수 R-ID부터 확인한다.
다중 세션이면 자신의 보고서에 코드와 입력 기준을 함께 기록하고 통합 담당자가 공통 EVIDENCE와 REQUIREMENTS에 반영한다.

- 각 R-ID에 실행 명령, 기대값의 근거, 실제 출력과 상태를 연결한다.
- 관련 코드나 입력이 바뀐 검증만 다시 실행하고, 제출 전에는 문서의 실제 실행 명령으로 전체 필수 흐름을 한 번 확인한다.
- 핵심 계산 하나는 구현 함수와 독립적인 작은 기준 사례로 검산한다. 경계값과 예외를 실제 요구에 따라 고른다.
- 중요한 테스트가 오류를 잡는지 확인한다. 성공 출력을 만들려고 기대값을 구현 결과에 맞추지 않는다.
- 서브의 완료 보고, HTTP 응답 성공, 사용자 화면 확인, 실제 과제 완료를 구분한다.
- PASS / FAIL / NOT_RUN / HUMAN_CHECK를 사용한다. 빈 검사나 미실행을 PASS로 처리하지 않는다.

필수 파일 경로와 저장 상태를 확인하고 미해결 항목을 사용자에게 짧게 알린다. 제출 버튼은 응시자가 직접 누른다. 실제 후속 서술형 답변에는 관여하지 않는다.
