# 세션 공유 문서

현재 상태는 [handoff/CURRENT.md](handoff/CURRENT.md), 공유 방법은 [handoff/README.md](handoff/README.md)를 읽는다.
[references](references/README.md)는 출처와 해석, [reports](reports/README.md)는 실제 작업과 검증을 기록한다.

새 세션은 공식 지침 → CURRENT → 배정받은 세션 인계 → 관련 보고서와 출처 순으로 읽는다.
세션의 대화는 자동 공유되지 않는다. 파일을 저장하고 경로를 전달하며 수신 세션이 다시 읽어야 한다.
여러 세션이 공통 원장을 동시에 편집하지 않는다. 통합 담당자가 요구와 결정을 반영한다.

사용 안내와 원본 자료는 .probe-kit에, 실제 공유 문서는 이 docs 폴더에 둔다.
기존 docs/README.md가 있으면 설치기는 보존하므로 필요한 링크만 통합 담당자가 추가한다.
