# 담당자 질문과 답변

각 세션은 `.probe-kit/scripts/question_log.py`로 아래에 문답 기록을 추가한다.
질문 초안, 실제 전송 질문, 답변, 정정과 사용자 요약을 구분한다. 질문/답변 원문은 별도 코드 블록에 전달받은 그대로 보존하고 AI 정리는 분리한다.
진행 세션, 기록 세션, 출처와 제공된 수신 시각을 남긴다. 기존 원문을 덮어쓰지 않고 같은 Q-ID 아래에 후속 기록을 추가한다.
`raw-bytes`는 코드 블록에 보존한 입력 바이트 수다. 줄바꿈/오탈자/코드 블록 문법을 바꾸지 않는다. 원문 미제공과 수신 시각 미확인은 추정하지 않는다.
원문 저장과 요구 확정은 다르다. S1이 Q-ID를 REQUIREMENTS, DECISIONS와 검증에 연결한다. 예상 서술형 문답은 S8의 SUB_RESULT에 저장한다.
