# 검증 기록

무엇을 실제로 실행/관찰했고 어떤 결과가 나왔는지 기록한다. 요구 ID는 REQUIREMENTS의 R-01 같은 번호다. 선택한 이유는 DECISIONS에 기록한다.
PASS = 확인 범위에서 통과, FAIL = 실패, NOT_RUN = 미실행, HUMAN_CHECK = 사람의 직접 확인이 남음. 직접 확인 결과를 받기 전에는 HUMAN_CHECK를 PASS로 처리하지 않는다.

| 요구 ID | 명령 | 실제 결과 | 상태 | 결과 파일 | 코드 위치 | 독립 검산 또는 오류 검출 확인 |
|---|---|---|---|---|---|---|

명령만 적은 것은 실행 증거가 아니다. 출력과 실패도 남긴다. 핵심 계산은 독립된 기준으로 확인한다.
