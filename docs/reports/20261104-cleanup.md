# 7개 세션 확정과 활성 파일 정리

2026-11-04. 앞선 [운영안 검토](20261104-team-design.md)에 이어 사용자 결정으로 기본 7개 역할을 확정했다.

## 변경

- 활성 파일 15개 정리. 중복 안내 3개는 foruser와 TEAM_PLAYBOOK에 통합하고 구형 파일 12개는 upstream 원본만 보존했다.
- 공용 TASK_SPEC/SUB_RESULT와 단일 로그 도구를 실행 경로에서 제거했다. 새 설치는 S1~S7 각각 TASK_SPEC, SUB_RESULT, HANDOFF를 준비한다.
- CURRENT는 7개 PLANNED 행으로 시작한다. 실제 작업과 쓰기 권한은 S1 배정 후 시작한다.
- 두 개발 세션, 데이터/알고리즘, 조사, 독립 검증, 기록의 파일 및 실행 자원 소유권을 분리했다. S1이 공통 원장을 유지한다.
- 원본 AGENTS/SUB_AGENTS는 보존하고 override에 구형 경로의 대안을 명시했다. Case 안내의 경로와 검증 연결도 갱신했다.
- probe-explain의 현재 코드 기반 5문항, 일반화한 가상 few-shot, 제출 전 설명 연습 절차를 함께 반영했다.
- 실제 시험의 문제 자료나 개인별 후속 문항 원문은 이 공개 저장소에 추가하지 않았다.
- 상세 제거 목록과 현재 대안: [CLEANUP](../CLEANUP.md).
