# 작업 및 검증 보고서

보고서는 무엇을 바꾸었고 무엇을 실제로 확인했는지 기록한다. 현재 작업 배정은 [CURRENT](../handoff/CURRENT.md)가 기준이다.
현재 보고서 목록과 읽을 순서는 CURRENT의 링크를 따른다.
설치된 과제에서는 개발 보고서를 과제 검증 결과로 쓰지 않는다.

[TEMPLATE.md](TEMPLATE.md)를 `<session-id>-<topic>.md`로 복사해 작성한다.
각 세션은 자기 보고서만 수정한다. 공유 색인 변경은 통합 담당자가 맡는다.
긴 로그 전체를 붙이지 않고 실행 명령, 중요한 출력, 종료 코드, 기준 코드와 입력, 미검증을 적는다.
후속 변경으로 결과가 달라지면 이전 근거를 보존하고 새 보고서에서 정정한다.
