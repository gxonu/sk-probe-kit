## 결정

- 질문은 열린 업무 질문에서 사례와 구체적 조건으로 좁힌다.
- 결정 기록은 기존 7개 열을 유지하고 이유에 업무 영향과 적용 조건, 한계에 재검토 조건을 포함한다.
- 공유 원장은 통합 담당자 한 명이 관리하고 각 세션은 개별 문서에 제안과 결과를 기록한다.
- 실제 과제의 공유 위치는 루트 docs다. 기존 .probe-kit/runtime 원장은 호환성을 위해 유지한다.
