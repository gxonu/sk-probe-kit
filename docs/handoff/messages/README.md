# 세션별 요청 파일

필요할 때만 `YYYYMMDD-HHMMSS-보낸세션-to-받는세션-주제.md`를 만든다.
보낸 세션이 새 파일을 작성하고 경로를 알려준다. 보낸 파일은 수정하지 않고 정정이나 답변은 새 파일로 연결한다.

```text
종류: REQUEST / RESPONSE / CORRECTION
보낸 세션:
받는 세션:
작성 시각 및 시간대:
관련 요청 파일:
관련 Q-ID / R-ID:
현재 근거와 파일 위치:
요청 또는 답변:
구현에 미치는 영향:
필요한 시점:
처리 결과 또는 남은 확인:
```

읽기만으로 작업 범위가 승인되거나 공통 요구가 변경되지는 않는다. 통합 담당자가 CURRENT와 원장에 반영했는지 확인한다.
동일 ID나 파일명이 이미 있으면 덮어쓰지 않고 다른 식별자를 사용한다.
