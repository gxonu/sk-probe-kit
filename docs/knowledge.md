# 반도체 자료 찾기

65개 개념의 본문과 공개 출처, 검색 인덱스를 포함한다. 개념과 용어를 이해하는 참고 자료이며 실제 과제의 임계값/사양을 대신 정하지 않는다.

```bash
python3 .probe-kit/scripts/knowledge.py search .probe-kit/knowledge/semiconductor HBM
python3 .probe-kit/scripts/knowledge.py search .probe-kit/knowledge/semiconductor 수율
```

검색 결과 `path`는 `.probe-kit/knowledge/semiconductor/` 기준이다. 관련 1~3개 항목만 읽고 과제의 단위, 측정 조건과 적용 범위를 확인한다. 중요한 수치와 주장은 연결된 공개 출처를 확인한다.
실제 업무 규칙이 없으면 자료 예시를 기준으로 넣지 말고 담당자 질문을 만든다. 사용한 개념/출처와 남은 가정은 결정 기록에 연결한다.
