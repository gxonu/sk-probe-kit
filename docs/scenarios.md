아래 4개 절은 스킬 묶음별 실행 점검이다.

## 데이터 처리 또는 판정

행의 의미와 키, 시간대, 적용일, 경계값의 포함 여부, 중복과 재측정의 의미부터 확인한다. 원본을 보존하고 변환 단계마다 입력 및 출력 건수와 제외 이유를 남긴다. 업무 확인 전에는 결측 대체, 중복 삭제, 합격 기준을 임의로 넣지 않는다. 작은 정상 사례와 경계 사례를 별개 계산으로 검산한다.

## 웹 서비스

누가 어떤 결정을 하려는지 확인하고 입력부터 결과 확인까지 한 동선을 완주한다. 인증과 저장 방식은 실제 요구에 맞춘다. 임의로 보안 기능을 끄지 않는다. 빈 입력과 실패 표시를 확인하고 응시자가 내장 Browser에서 직접 조작한다. 자동 브라우저 조작을 검증 수단으로 사용하지 않는다.

## 기존 코드 수정

먼저 재현 입력과 기대 동작을 고정한다. 실패를 재현한 뒤 가장 작은 변경으로 고친다. 관련 없는 리팩터링은 미룬다. 수정 전 실패와 수정 후 성공을 같은 재현 명령으로 남기고 회귀 영향을 확인한다.

## 정책 문서 또는 검색

문서 버전, 적용 대상, 시행일과 예외의 우선순위를 확인한다. 답변에 근거 위치를 연결하고 문서에 없는 내용은 확인 불가로 남긴다. 규칙과 정확 검색으로 충분하면 별도 모델이나 벡터 시스템을 추가하지 않는다. 외부 AI 연결 제한을 따른다.
