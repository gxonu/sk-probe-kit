# 공식 안내를 적용하는 기준

최신 운영 안내와 응시 화면 -> 실제 README/제출 규격 및 담당자 답변 -> 사용자 합의 -> 하네스 순서로 적용한다. 담당자의 업무 답변이 운영 규칙을 완화한다고 해석하지 않는다.

## 시작 시 실제로 확인할 값

- 과제 루트와 README, 별도 언어판/추가 자료, 필수 산출물과 실행 환경.
- 현재 회차의 시작과 전체 마감, 과제 제한, 후속 질문 생성 여유, 서술형 시간과 문항 수.
- 제공된 Codex와 허용 모델/도구, 화면 및 감독 규칙. 날짜/모델/포트는 과거 문서에서 복사하지 않는다.
- 업무 조건은 업무 담당자, 사용법은 Helper, 플랫폼 장애는 문제 신고로 확인한다.

## 기존 공식 안내에 근거한 운영 범위

근거는 2026-10-26 및 10-29 안내와 첨부 가이드다. 아래와 달라진 최신 명시 안내가 있으면 실제 내용을 CURRENT에 기록한다. 기존 안내만으로 재응시의 세부 시간을 확정하지 않는다.

- 제공된 Codex를 사용하고 임의 업데이트나 개인 API 키/별도 AI 연결을 하지 않는다.
- 공개 자료와 Skill/MCP/Plugin은 허용 범위에서 사용한다. 실제 사용한 저장소의 공개 유지 조건을 따른다.
- 문제, 파일, 결과물의 외부 전송 및 Git push, 개인 PC 자료 업로드를 하지 않는다.
- 감독/플랫폼 설정과 프로세스를 우회하거나 변경하지 않는다. Computer Use를 사용하지 않는다.
- 서비스 실행이 요구되면 안내된 바인딩으로 서버를 유지하고 응시자가 내장 Browser에서 직접 확인한다.
- 제출 확정 전 문서 작성에는 AI를 쓸 수 있다. 확정 뒤 실제 후속 서술형은 응시자가 직접 답한다.

## 공통 작업 원칙

구현 전에 필요한 조건을 묻고, 최초 계획에 합의하고, 작은 흐름부터 완주한다. 숫자와 판정은 코드로 확인한다. 완료에는 실제 실행 근거가 있어야 한다. 중요한 선택과 버린 대안을 기록하고 필요한 문맥만 읽는다.

구체적인 운영은 [AGENTS](../AGENTS.md) 한 곳에 있다. 후기와 출제 예상, 예시 숫자를 공식 조건이나 가점으로 취급하지 않는다.
