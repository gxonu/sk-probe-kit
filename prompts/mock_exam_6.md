# S8 예상 6문항과 보조 문항

제출 확정 전에 사용한다. S8의 기본 스킬은 `$probe-explain`이다. 이 프롬프트는 자동 예약을 하지 않는다.

## 질문과 답변 자료 만들기

```text
$probe-explain
나는 S8-explain이야. 자료 모드로 진행해.
지금은 제출 확정 전이고 과제 제출 예정까지 [분]분 남았어.
CURRENT와 내 TASK_SPEC을 읽고 현재 코드와 실제 작업 기록을 확인해.
설계 선택, 데이터 흐름/책임, 구현 범위/재현, 실패/복구,
위험/독립 검증, AI 협업의 6개 관점에서 주요 문항 6개를 만들어.
각 문항에 보조 질문 2개를 붙이고 주요/보조 질문 모두 답변 초안을 작성해.
각 질문의 요구 요소와 실제 파일/함수/기록 근거를 붙여.
기록에 없는 이유와 실행 성공은 만들지 말고 사용자 확인 필요 또는 NOT_RUN으로 남겨.
배정된 내 SUB_RESULT에 저장하고 내가 반드시 이해해야 할 빈칸부터 알려줘.
```

## 실제 설명 연습

```text
$probe-explain 연습 모드. 준비한 문항 중 중요한 것부터 하나씩 물어봐.
먼저 답변이나 힌트를 보여주지 말고 내가 답한 뒤 코드 근거로 피드백해.
질문에 포함된 요구 요소 중 빠뜨린 내용과 근거 없는 주장을 짚어줘.
```

## 변경분만 갱신

```text
$probe-explain 갱신 모드. 변경된 파일과 DECISIONS/EVIDENCE를 확인해.
기존 6문항과 답변 중 영향받는 부분만 갱신하고 코드 기준을 다시 기록해.
현재 구현과 다른 이전 답변을 남겨두지 말고 정정 이유를 표시해.
```

보조 문항 수와 준비 시간은 사용자가 바꿀 수 있다. 실제 문항 수, 문구와 제출 자료 수집 범위가 확정됐다고 가정하지 않는다.
