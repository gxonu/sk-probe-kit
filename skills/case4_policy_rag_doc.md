# 문서와 규칙 기반 판단: 선택 점검

실제 과제가 정책 판단, 자동화, 검색/분류 또는 대안 비교를 요구할 때 사용한다. 공통 프로토콜은 .probe-kit/AGENTS.md를 따른다.

1. 문서/데이터 버전, 적용 대상과 시행일, 결과를 사용하는 사람의 판단 목적을 확인한다.
2. 규칙과 근거 위치를 찾고 예외 우선순위, 경계값과 정보 부족의 처리를 확인한다. 문서 밖 내용을 확정 조건으로 만들지 않는다.
3. 조건문/정확 검색/단순 집계로 충분한지 먼저 판단한다. RAG, 벡터 DB 또는 모델은 실제 요구와 허용 환경에서 필요한 경우에만 검토한다.
4. 숫자와 규칙 판정은 재현 가능한 코드로 수행한다. 근거 부족은 보류/확인 필요로 드러내고 그럴듯한 결론으로 채우지 않는다.
5. 전략 비교는 선택 기준, 가중치의 출처와 단위, 불확실성을 명시한다. 데이터에 없는 점수나 이익을 만들어내지 않는다.
6. 정상, 경계/충돌, 근거 부족 사례를 실제 규칙에 맞춰 검증한다. 정확도 수치에는 실제 표본 수, 기준과 결과를 붙인다.
7. 복합 과제는 앞 단계 출력과 다음 단계 입력 계약부터 나눈다. 기준 판정, 화면, 보고서가 같은 상태와 단위를 사용하도록 확인한다.
8. 자기 SUB_RESULT에 근거 위치, 선택과 버린 대안, 실제 검증과 한계를 적고 S1이 공통 원장에 반영한다.
