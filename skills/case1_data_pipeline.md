# 데이터 처리와 판정: 선택 점검

공통 프로토콜은 .probe-kit/AGENTS.md를 따른다. 입력 데이터로 결과를 계산/판정하는 부분에만 적용한다. 아래 규칙과 예시를 실제 업무 조건으로 가정하지 않는다.

1. 행의 의미, 기본 키/결합 키, 행 수, 중복과 결측, 단위, 시간 범위를 작은 코드 요약으로 확인한다. 표본이면 표본이라고 표시한다.
2. 결측이 미측정/해당 없음/수집 오류 중 무엇인지, 취소와 중복을 분모에 포함하는지, 기준의 등호/적용 시점을 확인한다.
3. 실제 숫자가 있는 기준 2~3안을 만들고 결과를 바꾸는 미확인 조건만 담당자에게 확인할 초안으로 보낸다. 전송은 사용자 담당이다.
4. 입력 -> 변환 -> 판정/집계 -> 출력 계약을 정한다. 숫자는 코드로 계산하고 단계별 입력/유효/제외/보류 건수와 이유를 남긴다.
5. 단순 기준안부터 완주한다. 개선은 같은 입력과 품질 지표, 실행 시간으로 비교한다. 모델이 필요하면 시간/그룹 누수와 평가 분할을 먼저 확인한다.
6. 생성 함수와 독립된 작은 입력/기대 결과로 핵심 계산을 검산한다. 빈 입력, 중복 키, 결합 누락, 임계값 바로 아래/같음/위를 실제 요구에 맞춰 선택한다.
7. 출력 열/자료형/정렬/단위/파일명은 README 규격을 따른다. 처리 실패나 판정 보류를 정상 결과와 구분한다.
8. S4는 데이터와 계산, S6는 독립 검증을 맡도록 파일 범위를 나눌 수 있다. 작업과 증거는 자기 SUB_RESULT에, 공통 요구/결정은 S1이 반영한다.

반도체 용어가 실제로 등장하면 선택 설치한 knowledge.py로 필요한 개념만 찾는다. 지식 문서의 예시 임계값을 실제 사양으로 쓰지 않는다.
