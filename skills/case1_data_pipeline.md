# 데이터 정제, 집계와 제조 판정

Case 1/5 및 복합 과제의 데이터 단계에 사용한다. 공통 운영은 AGENTS와 TEAM_PLAYBOOK을 따른다.

1. 작은 표본과 전체 크기부터 확인한다. 행의 의미, 키/중복, 단위, 시간대/기준일, 결측/센티널, 범위, 원본과 파생 컬럼을 구분한다. 표본 결과를 전체 통계로 보고하지 않는다.
2. 중복의 의미, 취소/결측의 분모 포함, 경계 등호, 재측정과 기준 변경일을 문서에서 찾고 모호한 조건만 `$probe-interview`로 묻는다. 반도체 자료는 개념 이해용이며 예제 수치를 공정 기준으로 쓰지 않는다.
3. 원본을 보존하고 단순 기준안으로 대표 입력을 최종 출력까지 연결한다. 단계마다 입력/출력 건수, 제외/보류 이유를 남긴다. 시간/사건 키를 단순 문자열 순서로 추정하지 않는다.
4. 핵심 판정은 독립된 작은 입력으로 검산한다. 중복, 빈 값, 취소, 경계, 자정/시간대, 정보 이용 시점 중 실제로 해당하는 조건을 확인한다. 정답이 불명확하면 데이터에 맞춰 임의 정책을 만들지 않는다.
5. S4의 개선은 동일 입력/지표/예산으로 단순 기준안과 비교한다. 필수 제약 충족과 목적값 개선을 구분하고, 시간 제한/해 없음/미할당 상태를 실제 구현대로 표현한다. 특정 최적화 도구를 강제하지 않는다.
6. 실제 결과는 SUB_RESULT, 선택은 S1의 DECISIONS, 검증은 EVIDENCE, 질문 원문은 QUESTION_LOG에 연결한다. S8이 설명할 선택/약점/조건 변경 시 영향을 남긴다.

반도체 용어 검색: `python3 .probe-kit/scripts/knowledge.py search .probe-kit/knowledge/semiconductor <용어>`.
